<h2>La forma di un programma C</h2>

<p>
  Un programma C è testo sorgente che descrive dichiarazioni e istruzioni. Nel modello di programma ospitato, il punto d'ingresso convenzionale è la funzione <strong>main</strong>, che restituisce al sistema un codice di uscita. La forma più semplice è questa:
</p>

```c
#include <stdio.h>

int main(void)
{
    printf("Ciao, mondo!\n");
    return 0;
}
```

<p>
  La direttiva <strong>#include</strong> rende disponibili le dichiarazioni dell'header standard <strong>stdio.h</strong>. La funzione <strong>printf</strong> scrive sul flusso di output standard; <strong>\n</strong> conclude la riga. Le parentesi graffe delimitano il corpo della funzione e il punto e virgola termina un'istruzione.
</p>

<Definition term="Funzione main">
  <p>Nel modello ospitato, <strong>int main(void)</strong> è una forma valida e portabile della funzione iniziale. Restituire zero segnala una conclusione riuscita; un valore diverso da zero segnala una condizione anomala.</p>
</Definition>

<p>
  C distingue maiuscole e minuscole: <strong>main</strong> e <strong>Main</strong> sono identificatori diversi. Le parole chiave, come <strong>int</strong> e <strong>return</strong>, hanno un significato riservato. I commenti con <strong>//</strong> terminano a fine riga; quelli tra <strong>/&#42;</strong> e <strong>&#42;/</strong> possono estendersi su più righe.
</p>

</section>

<h2>Compilare e leggere gli errori</h2>

<p>
  Il file sorgente, per esempio <strong>ciao.c</strong>, non è ancora il programma eseguibile. Una toolchain traduce il testo in più passaggi: il preprocessore espande direttive e macro; il compilatore traduce il C; l'assemblatore produce codice oggetto; il linker collega il codice oggetto alle librerie. I dettagli variano, ma questa distinzione aiuta a capire i messaggi diagnostici.
</p>

<p>Con GCC o Clang, una riga di comando essenziale è:</p>

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic ciao.c -o ciao
./ciao
```

<p>
  L'opzione <strong>-std=c17</strong> seleziona il dialetto C17; <strong>-Wall</strong>, <strong>-Wextra</strong> e <strong>-Wpedantic</strong> chiedono avvisi aggiuntivi. Un warning non è automaticamente un errore, ma merita attenzione: spesso anticipa un difetto. Se il compilatore indica una riga, leggi anche quelle precedenti: la causa può essere una parentesi o un punto e virgola dimenticato.
</p>

<Note title="Errore, warning e comportamento indefinito">
  <p>
    Un errore impedisce la traduzione; un warning segnala codice sospetto o non portabile. Il <em>comportamento indefinito</em> è diverso: lo standard non impone cosa debba accadere durante l'esecuzione. Il programma può sembrare funzionare e fallire con un'altra ottimizzazione o su un'altra macchina.
  </p>
</Note>

<h2>Variabili e tipi fondamentali</h2>

<p>
  Una variabile è un oggetto identificato da un nome, con un tipo e una durata di vita. Il tipo stabilisce quali valori può rappresentare e quali operazioni hanno significato. Prima di usarla, una variabile automatica va inizializzata: leggere un valore indeterminato non è un modo valido per ottenere un numero casuale.
</p>

```c
int tentativi = 3;
double temperatura = 21.5;
char iniziale = 'C';
_Bool pronto = 1;

tentativi = tentativi + 1;
```

<p>
  Il nome <strong>char</strong> indica un'unità di memoria sufficiente a contenere un membro del set di caratteri di base; non promette che ogni carattere Unicode occupi un singolo char. Per i caratteri si usano apici singoli, per le stringhe doppi apici. Con <strong>sizeof</strong> si ottiene la dimensione in byte di un tipo o di un oggetto, come valore di tipo <strong>size_t</strong>.
</p>

<p>
  Scegli il tipo in base al significato del dato, non soltanto al numero di cifre atteso. Per quantità non negative e dimensioni si incontrano spesso tipi unsigned o size_t; per valori che possono essere negativi, un tipo signed. Gli header <strong>limits.h</strong> e <strong>float.h</strong> descrivono i limiti disponibili nell'implementazione.
</p>

<section className="book-section" id="sec-io">

<h2>Input e output</h2>

<p>
  <strong>printf</strong> combina testo e specificatori di formato. Il tipo dell'argomento deve corrispondere allo specificatore: per esempio <strong>%d</strong> per int, <strong>%f</strong> per double nelle chiamate variadiche a printf, <strong>%c</strong> per un carattere promosso a int, <strong>%s</strong> per una stringa terminata da zero e <strong>%zu</strong> per size_t.
</p>

```c
#include <stdio.h>

int main(void)
{
    int eta = 0;

    printf("Quanti anni hai? ");
    if (scanf("%d", &eta) != 1) {
        fprintf(stderr, "Input non valido\n");
        return 1;
    }

    printf("Il prossimo anno ne avrai %d.\n", eta + 1);
    return 0;
}
```

<p>
  <strong>scanf</strong> riceve indirizzi perché deve poter scrivere negli oggetti: <strong>&amp;eta</strong> significa «indirizzo di eta». Il valore restituito indica quanti elementi sono stati assegnati. Ignorarlo può lasciare variabili non aggiornate e far proseguire il programma con dati non validi. Per leggere righe di testo e gestire input più articolato, <strong>fgets</strong> è spesso una scelta più controllabile; la useremo nel capitolo sulle stringhe.
</p>

<Note title="Il formato è un contratto">
  <p>
    Un formato errato in printf o scanf può produrre comportamento indefinito. Non usare <strong>%d</strong> per un double e non passare a scanf il valore della variabile quando serve il suo indirizzo. Le funzioni di formato non verificano automaticamente che il testo corrisponda al tipo previsto.
  </p>
</Note>
