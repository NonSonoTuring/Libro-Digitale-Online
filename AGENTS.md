# Istruzioni per gli agenti

- Esegui solo le modifiche richieste dall'utente; non modificare file non coinvolti.
- Prima di cambiare la documentazione, leggi le guide pertinenti in `docs/`.
- Mantieni i contenuti dei capitoli in `.mdx`, le risorse statiche nelle cartelle `assets/` e la logica interattiva nei componenti dedicati.
- Non aggiungere dipendenze o tecnologie senza una richiesta o una motivazione esplicita.
- Rispetta la lingua e la formattazione già usate nei file esistenti.
